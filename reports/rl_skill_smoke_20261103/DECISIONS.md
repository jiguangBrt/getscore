# 正式训练前需要决定的设置

2026-11-03。本次仅验证三类技能训练链路，不做评测。表中的值是推荐，不构成用户已经决定的正式配置。实际 smoke 值记录于 configs/smoke.json；源码继承参数、模型结构与完整依赖版本另行记录。

## 先决定任务含义

| 决策 | 本次临时设置 | 后续推荐与影响 |
|---|---|---|
| 训练哪个模型 | 当前官方 pi05_libero，转为 RLinf PyTorch 布局 | 就用pi05_libero |
| 三技能的语言条件 | 全部为 pick up the white mug | 就用 pick up / place upright / pick up and place upright |
| 一个模型还是三套技能策略 | 同一原模型，三技能采样后一次联合更新 | 共享同一个模型，联合更新 |
| 训练物体 | 一个白杯 | 先白杯、黄白杯，摩卡壶等long任务中出现的所有物体 |
| 抓取部位 | 不指定，不奖励杯柄 | 保持开放策略 |
| 放置目标 | 环境 plate_1 附近 | 明确区域、支撑面及位置容差； |
| 原始场景或自建技能场景 | LIBERO-PRO 原场景 task 6 的技能重置包装 | 原场景承载自定义技能任务，单独标记任务版本|
| 抓取终止时机 | 抬起并保持即结束 | 不引用rpent,单独训练抓取，放下以及扶正 |
| 扶正含义 | 侧翻后直立、释放并稳定在目标区域 | 原地扶正，如果原地不好扶正可以就近放置 |

## 初态与奖励

| 决策 | 本次临时设置 | 后续推荐与影响 |
|---|---|---|
| 抓取初态距离 | 原任务稳定初态 | 初始夹爪位置在目标的几何正上方附近，因为rpent调用pi0之前会移动到他认为的正上方 |
| Place 初态 | 脚本真实接触夹持、提升后保存；无物体焊接/瞬移夹持 | 混合多种真实抓取姿态，初态脚本动作排除出 on-policy 数据 |
| Upright 初态 | 侧翻约 90° 后自然落稳 | 从轻微倾斜逐渐扩大到侧翻；杯柄朝向随机，保留困难方向 |
| 域随机化 | 单一 smoke 初态，seed 42 | 先位置/朝向，不需要加入噪点，摩擦力等东西，这些物理量的设置完全和liberopro的设置保持一致即可 |
| 抓起高度 | 5 cm | 推荐 5 cm，按物体大小校准 |
| 抓取保持时间 | 10 native steps = 0.5 s | 2 s，排除瞬时弹起，也避免抓起后脱手 |
| 直立误差 | 15° | 5°以内；这样才能放平 |
| 稳定观察时间 | 20 steps = 1 s | 推荐 4 s，必要时更长检查慢倾倒 |
| 静止阈值 | 线速度 0.03 m/s、角速度 0.3 rad/s | 先按物理状态校准，不能只看倾角，速度必须静止， |
| 目标位置容差 | 距盘中心 10 cm | 这个判定可以调研一下libero的判定规则 |
| 松手/撤离 | 无夹持、夹爪开度>0.06 m、EEF 离杯中心上方点>0.10 m | 应按夹爪/杯型校准，需有支撑接触 |
| 成功奖励 | +1 | 推荐 +1，训练时保留逐项成功条件 |
| 掉落失败 | 物体低于桌面 10 cm，-1 并终止 | 推荐检测掉桌/不可恢复状态，而非任意碰撞均扣分 |
| 塑形 | 0.1 × (gamma*Phi(next)-Phi(current)) | 推荐小权重；是否采用纯稀疏奖励应单独决定 |
| 步惩罚 | -0.0001/native step | 建议保守，过大会使模型偏向早停或投机 |
| 真值使用 | 仅奖励/诊断；策略 RGB+机器人状态 | 保持；若 critic 使用物体真值需作为单独决定 |
| 是否需要示范热身 | 本轮不做 | 新技能零成功时优先 20–50 条多样成功示范/技能尝试起步 |

## 算法与模型更新

| 决策 | 本次临时设置 | 后续推荐与影响 |
|---|---|---|
| 算法 | RLinf Flow-SDE + PPO 模型采样/损失，最小同步驱动 | 首轮继续 PPO|
| 更新范围 | 仅动作输出层 action_out_proj 与 value head，一次更新；其余冻结 | 启用lora |
| value head | VLM 前缀特征池化后接 critic，初始随机 | 推荐此路径；critic 热身步数需决定，正式阶段可先试少量热身 |
| 数值精度 | bf16 骨干，归一化/stem/动作与价值头保留 fp32 | 与当前 RLinf 实现对齐，避免全模型强制 bf16 |
| 归一化统计 | 当前 checkpoint 原统计、quantile norm | 不擅自重算；新数据分布明显变化后另定 |
| 离散状态提示 | False，继承当前 pi05_libero | 保持 checkpoint 对齐；并非所有 pi05 checkpoint 都相同 |
| 网络动作长度 | 10 | 保持 checkpoint 长度，不因执行长度而改网络结构 |
| 每次执行长度 | 前5步 | 8 |
| Flow 去噪步数 | 10 | 10 |
| 探索强度 | Flow-SDE noise_level 0.5 | 推荐从0.5起；根据动作稳定性调整，不把单次失败当作调参依据 |
| 概率计算 | 非joint，存去噪链与采样步；执行坐标 logprob 求和 | 与 Flow-SDE 路径对齐，不能用只有最终动作的旧服务替代 |
| actor 学习率 | 1e-6 | 推荐先1e-6 |
| critic 学习率 | 1e-5 | 推荐保守起步 |
| 优化器 | AdamW，betas=(0.9,0.95)，eps=1e-8，weight_decay=0.01 | 建议暂保留 |
| 梯度裁剪 | 全局范数1.0 | 推荐1.0 |
| PPO clipping | 0.2 | 推荐0.2 |
| Value clipping / loss | 0.2，Huber delta 10，critic系数1 | 推荐起步保持，需结合价值目标尺度 |
| 折扣 | 每native step 0.998，每5步约0.99 | 推荐明确计时单位； |
| GAE lambda | 每chunk 0.95 | 推荐0.95 |
| 优势归一化 | 开启 | 推荐开启； |
| KL / entropy | 均0 | Flow-SDE 官方起点entropy=0； |
| 每批重复更新 | 一次 | 推荐先1次； |
| 任务采样比例 | 每类一条 | 推荐起步抓取40%、放置40%、扶正20% |
| 更新batch | 仅6个chunk，三技能各2个 | 正式试训建议先8个环境×32个chunk=256，再按显存调整 |
| microbatch/梯度累积 | microbatch1，累积6，optimizer只step一次 | 正式推荐先microbatch1–2，global batch独立决定 |
| 样本时效 | 固定v0采样，更新至v1后同步 | 推荐同步，先不引入异步旧策略数据 |
| 各阶段预算 | 三类各200 native steps、最多1次更新 | 后续短试训建议先10–30次更新检查链路，再决定总预算；本轮不会自动继续 |
| 超时bootstrap | 原始最终观测上估计V；真正terminal置零 | 保留，不能用reset后的观测作为最终状态 |
| 学习率调度 | 单步固定LR，无调度 | 正式推荐先短warmup再固定/衰减，需定总步数后配置 |
| 旧技能保持 | 本轮不做额外训练 | 正式需决定是否混合旧示范/BC约束以及比例 |

## 运行、记录与结束

| 决策 | 本次临时设置 | 后续推荐与影响 |
|---|---|---|
| GPU | 物理0 learner、1 rollout、3 EGL；不用2与4–7 | 保持小规模职责分离，批量扩大后再分片 |
| 并发环境数 | 一次一个，三技能顺序跑 | 先试8 如果可以的话提升到16 |
| CPU线程 | OMP/MKL各2 | 先限制，按渲染/仿真吞吐调整 |
| 控制频率 | 20Hz | 继承LIBERO设置，改变会影响奖励保持时间和控制语义 |
| RGB | 两相机256×256渲染，模型224×224 | 与已有处理方式对齐 |
| 随机种子 | 42，单种子 | 单种子 |
| 视频 | 每条训练轨迹保存；20fps；主/腕视图与奖励叠字 | 正式仅抽样，避免全量视频拖慢训练 |
| 保存内容 | 一步的可训练权重+优化器+RNG+配置，基础权重保持独立 | 正式推荐latest+best+少量里程碑；best依赖后续用户同意的评测 |
| 保存间隔 | 仅末尾一次 | 正式按可接受损失的训练时间定，不建议每步保存GB级优化器 |
| 继续/恢复 | 验证保存加载和v1权重同步，不再采样评测 | 正式需同时恢复环境/采样器与CPU/CUDA/Python/NumPy RNG |
| 评测 | 完全关闭，无成功率统计 | 每1小时评测 |
| 停止规则 | 1次optimizer更新完成即停止；异常立即保留记录 | 正式需定总预算、异常阈值、无进展停止条件，不能默认为无限运行 |
| 代码/依赖来源 | 全部位于/data/wangyihan；公开源码独立快照与全新环境 | 禁止指向其他用户目录，保留来源与版本记录 |
